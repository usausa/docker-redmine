# patches/ — プラグインへのパッチ置き場

`<プラグイン名>.patch` という名前で置くと、`Dockerfile` がそのプラグインの展開直後に
`patch -p1` で適用します。**空でもビルドは成功します。**

## 現在の状態: 0件

この構成は Redmine 本体とプラグインのソースを変えない方針です。パッチは、上流の修正を待てない不具合があるときの最後の手段として使います。

## 使い方

```bash
# プラグインのリポジトリで差分を作る
git -C <plugin-dir> diff > patches/<plugin_name>.patch
```

> ⚠️ **コンテナ内でプラグインのソースを直接編集しないこと。** 再作成で消えます。
> 必ずパッチとしてここに置き、`docker compose build` で適用してください。
